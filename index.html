Plot a trend

This layer is one row per well/POD, not repeated measurements — so for each attribute you check, this averages that value across all sites inside the drawn filter, by year, and plots it as its own trend line (e.g. "has average well depth here gotten deeper over the decades?"). It's not a per-site history over time.
